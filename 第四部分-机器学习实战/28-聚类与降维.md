## 28.1 无监督学习回顾

前面的回归和分类都是**监督学习**——数据带标签（正确答案）。而**无监督学习**的数据**没有标签**，目标是让模型自己发现数据内在的结构。两大典型任务：

- **聚类**：把相似的样本自动分成若干组。例如电商给用户分群、把新闻按主题归类。
- **降维**：在尽量保留信息的前提下减少特征数量。用于可视化、压缩、去噪、加速训练。

---

## 28.2 K-Means 聚类

**K-Means** 是最常用的聚类算法。思想很直观：

1. 你指定要分成 **K** 个簇。
2. 算法随机放 K 个“簇中心”。
3. 每个样本归到离它最近的中心，形成 K 个簇。
4. 把每个中心移动到本簇所有点的平均位置。
5. 重复 3~4，直到中心不再移动。

> **打个比方**：在一座城市里开 K 个快递站。先随便选 K 个位置开站；每户人家都去离自己最近的站取件；然后把每个站搬到“它所服务的所有人家”的正中间；搬完后，有些人家发现别的站更近了，就换站取件……如此反复，直到没有站需要再搬。最后每个站和它服务的人家，就是一个“簇”。

### 准备数据并聚类

我们先用 `make_blobs` 生成几团明显的数据来演示：

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

# 生成 4 团数据（我们假装不知道是 4 团）
# make_blobs 还会返回每个点真正属于哪一团，这里用 _ 接收并丢弃——无监督学习用不到标签
X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
labels = kmeans.fit_predict(X)      # 训练并返回每个样本的簇编号

print("前 10 个样本的簇：", labels[:10])
print("簇中心：\n", kmeans.cluster_centers_.round(2))
print("Inertia（簇内误差）：", round(kmeans.inertia_, 1))
```

- `fit_predict` 一步完成训练并返回聚类标签（0~K-1）。
- `cluster_centers_` 是每个簇的中心坐标。
- `inertia_` 是“簇内平方和”——所有点到各自簇中心距离的平方和，**越小说明簇越紧凑**。
- `n_init=10`：用 10 组不同的初始中心各跑一次取最好的，避免陷入差的局部解。

> **簇的编号只是“名字”，没有顺序和含义**：簇 0、簇 1 只是为了区分不同的组，换一个随机种子，同一组点可能就被叫作簇 2。“簇 0”**不等于**“第 0 类”。

### 可视化聚类结果

```python
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei", "PingFang SC", "WenQuanYi Zen Hei"]
plt.rcParams["axes.unicode_minus"] = False

plt.scatter(X[:, 0], X[:, 1], c=labels, cmap="viridis", alpha=0.6)
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1],
            c="red", marker="X", s=200, label="簇中心")
plt.title("K-Means 聚类结果")
plt.legend()
plt.show()
```

`c=labels` 让不同簇显示成不同颜色，红色大叉是簇中心。

## 28.3 如何选择 K：肘部法则

现实中我们并不知道该分几类。**肘部法则（Elbow Method）**帮我们选：尝试不同的 K，画出 K 与 inertia 的关系曲线。inertia 会随 K 增大而减小，但在“合适的 K”之后下降会明显变缓，曲线出现一个“肘部”拐点。

```python
inertias = []
K_range = range(1, 8)
for k in K_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(X)
    inertias.append(km.inertia_)

plt.plot(K_range, inertias, marker="o")
plt.xlabel("K（簇数）")
plt.ylabel("Inertia")
plt.title("肘部法则")
plt.show()

print(dict(zip(K_range, [round(i) for i in inertias])))
```

对本例数据，inertia 从 K=1 到 K=4 急剧下降，之后趋于平缓——“肘部”出现在 **K=4**，这正是我们生成数据时的真实簇数。

## 28.4 轮廓系数：评估聚类好坏

聚类没有真实标签可对照，怎么评估质量？**轮廓系数（Silhouette Score）**衡量“簇内紧密、簇间分离”的程度，取值 -1~1，**越接近 1 越好**。

直观理解：对每个点，比较“它离**自己簇**里其他点有多近”和“它离**最近的另一个簇**有多远”：

- 接近 1：离自己人很近、离外人很远——分得好；
- 接近 0：站在两个簇的边界上，分到哪边都差不多；
- 小于 0：离别的簇反而更近——很可能分错了。

所有点的平均值就是整体的轮廓系数：

```python
from sklearn.metrics import silhouette_score

score = silhouette_score(X, labels)
print(f"轮廓系数：{score:.3f}")      # 本例约 0.83，说明聚类效果很好
```

可以用它辅助选 K：对不同 K 计算轮廓系数，选最高的那个。

## 28.5 降维与 PCA

当数据有很多特征（几十上百维）时，我们无法直接可视化，计算也慢。**降维**能把高维数据压缩到低维，同时尽量保留原有信息。

**主成分分析（PCA, Principal Component Analysis）**是最经典的降维方法。它找到数据中方差最大的几个方向（“主成分”），把数据投影上去。

> **打个比方**：给一个立体的茶壶拍照（三维变二维），从正上方拍只能看到一个圆，从侧面拍能看到壶嘴、壶把和壶身。PCA 做的就是**自动找到那个“信息最多”的拍摄角度**——让数据在照片上铺得最开（方差最大），尽量少地丢失细节。

> PCA 对特征量纲敏感，使用前通常要先**标准化**。

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

iris = load_iris()
X_scaled = StandardScaler().fit_transform(iris.data)   # 4 个特征，先标准化

pca = PCA(n_components=2)          # 降到 2 维
X_pca = pca.fit_transform(X_scaled)

print("降维前：", X_scaled.shape)   # (150, 4)
print("降维后：", X_pca.shape)      # (150, 2)
print("各主成分解释的方差比例：", pca.explained_variance_ratio_.round(3))
print("累计解释比例：", round(pca.explained_variance_ratio_.sum(), 3))
# 约 0.958，即 2 个主成分保留了原始 4 维约 96% 的信息
```

`explained_variance_ratio_` 告诉我们每个主成分保留了多少信息。这里用 2 维就保留了约 96%，非常划算——既能画图，又几乎不丢信息。

### 用 PCA 可视化

把 4 维鸢尾花降到 2 维后就能画在平面上，用真实品种上色，可以看到三个品种分得很开：

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 5))
scatter = plt.scatter(X_pca[:, 0], X_pca[:, 1], c=iris.target, cmap="viridis")
plt.xlabel("主成分 1")
plt.ylabel("主成分 2")
plt.title("鸢尾花数据 PCA 降维可视化")
plt.colorbar(scatter, label="品种")
plt.show()
```

## 28.6 综合：聚类能“找回”真实品种吗？

无监督方法可以组合使用，也可以拿来验证“数据里是否真的有结构”。比如对鸢尾花（假装没有标签），先聚类，再和真实品种对比：

```python
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
cluster_labels = kmeans.fit_predict(X_scaled)

# 调整兰德指数：衡量聚类结果与真实标签的一致性（1 表示完全一致）
ari = adjusted_rand_score(iris.target, cluster_labels)
print(f"聚类与真实品种的一致性 (ARI)：{ari:.3f}")   # 约 0.62
```

ARI 约 0.62，说明在完全没有标签的情况下，K-Means 也能把鸢尾花大致分成对应三个品种的簇（其中两个品种本身就比较像，不易完全分开）。这展示了无监督学习的价值——从无标签数据中发现真实存在的结构。

> **为什么不直接用准确率？** 因为簇编号是随意的。本例中 K-Means 把 setosa 叫作“簇 1”，而 setosa 的真实标签是 0——如果直接用 `accuracy_score(iris.target, cluster_labels)`，只能得到 0.24，看起来像是“分得很差”，其实只是**名字没对上**。ARI 只关心“哪些样本被分在了一起”，不在乎簇叫什么名字，所以适合用来比较聚类结果和真实标签。

也可以先用 PCA 降到 2 维，再在 2 维数据上聚类——维度更低、计算更快，还能直接画出来看：

```python
cluster_labels_2d = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(X_pca)
print(f"在 PCA 2 维数据上聚类的 ARI：{adjusted_rand_score(iris.target, cluster_labels_2d):.3f}")   # 约 0.62
```

本例中降到 2 维后聚类效果几乎没有损失，因为这 2 维已经保留了约 96% 的信息。

## 新手常见错误

### ❶ 聚类前没有标准化（不报错，但结果差很多）

```python
from sklearn.datasets import load_wine

wine = load_wine()
raw = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(wine.data)
scaled = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(
    StandardScaler().fit_transform(wine.data))
print(adjusted_rand_score(wine.target, raw))      # 约 0.37
print(adjusted_rand_score(wine.target, scaled))   # 约 0.90
```

**原因**：K-Means 按“距离”分组。红酒数据里有的特征在 1000 左右，有的在 0.1 左右，不标准化时，数值大的特征几乎决定了一切。PCA 同理。
**改法**：K-Means、PCA、KNN 这类基于距离 / 方差的方法，使用前先 `StandardScaler`。

### ❷ 用准确率比较簇标签和真实标签

```python
from sklearn.metrics import accuracy_score
accuracy_score(iris.target, cluster_labels)       # 0.24，严重低估
```

**原因**：簇编号和真实类别编号没有对应关系（见 28.6 节）。这个错误**不会报错**。
**改法**：用 `adjusted_rand_score`（ARI）等专门比较聚类结果的指标。

### ❸ 对只有 1 个簇的结果计算轮廓系数

```python
silhouette_score(X, KMeans(n_clusters=1, n_init=10).fit_predict(X))
```

```
ValueError: Number of labels is 1. Valid values are 2 to n_samples - 1 (inclusive)
```

**原因**：轮廓系数要比较“簇内”和“簇间”的距离，只有 1 个簇时没有“簇间”可比。
**改法**：用轮廓系数选 K 时，K 从 **2** 开始试（肘部法则则可以从 1 开始）。

### ❹ PCA 的维度设得比原始特征还多

```python
PCA(n_components=5).fit(X_scaled)     # 鸢尾花只有 4 个特征
```

```
ValueError: n_components=5 must be between 0 and min(n_samples, n_features)=4 with svd_solver='covariance_eigh'
```

**原因**：降维只能“减少”维度，主成分个数不能超过原有特征数。
**改法**：`n_components` 取小于特征数的值；也可以写成 0~1 之间的小数，例如 `PCA(n_components=0.95)` 表示“保留 95% 信息所需的最少维度”。

## 本章小结

- 无监督学习无标签，发现数据结构：**聚类**（分组）、**降维**（压缩特征）。
- **K-Means**：指定 K，迭代地“分配-更新中心”；`fit_predict` 得簇标签，`inertia_` 看紧凑度，`n_init=10` 更稳。
- 选 K：**肘部法则**（inertia 曲线拐点）；评估：**轮廓系数**（越接近 1 越好）。
- **PCA** 降维：保留方差最大的方向；用前先标准化；`explained_variance_ratio_` 看保留信息量。
- 降到 2 维可用于可视化；无监督方法可组合（如降维 + 聚类）。
- 簇编号只是名字，和真实类别比较时用 ARI 而不是准确率；基于距离的方法先标准化。

**第 1 题**：

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X, _ = make_blobs(n_samples=200, centers=3, cluster_std=1.0, random_state=0)
labels = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(X)
print(labels[:10])
print(f"轮廓系数：{silhouette_score(X, labels):.3f}")
```

**第 2 题**：

```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

inertias = [KMeans(n_clusters=k, random_state=42, n_init=10).fit(X).inertia_ for k in range(1, 8)]
plt.plot(range(1, 8), inertias, marker="o")
plt.xlabel("K")
plt.ylabel("Inertia")

```

**第 3 题**：

```python
from sklearn.metrics import silhouette_score
for k in [2, 3, 4, 5]:
    lb = KMeans(n_clusters=k, random_state=42, n_init=10).fit_predict(X)
    print(f"K={k}: {silhouette_score(X, lb):.3f}")
# K=3 通常最高
```

**第 4 题**：

```python
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

wine = load_wine()
Xs = StandardScaler().fit_transform(wine.data)
pca = PCA(n_components=2)
X2 = pca.fit_transform(Xs)
print("保留信息：", round(pca.explained_variance_ratio_.sum(), 3))   # 约 0.554

plt.scatter(X2[:, 0], X2[:, 1], c=wine.target, cmap="viridis")
plt.title("红酒数据 PCA 降维")
plt.show()
```

**第 5 题**：当特征极多（维度高）、存在冗余/相关特征、或需要可视化、加速训练、缓解“维度灾难”时，可先降维再建模。代价：降维会**丢失部分信息**，且 PCA 得到的新特征是原特征的线性组合，**失去了原本的业务可解释性**（“主成分1”不再对应某个具体指标）。
