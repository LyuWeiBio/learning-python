## 7.1 列表：有序的数据集合

前面我们的变量一次只能存一个值。**列表（list）**可以在一个变量里存放**一串有序的值**，用方括号 `[]` 表示，元素之间用逗号分隔：

```python
fruits = ["苹果", "香蕉", "橙子"]
numbers = [10, 20, 30, 40]
mixed = [1, "你好", 3.14, True]    # 列表可以混装不同类型
empty = []                        # 空列表
```

列表里可以放任意类型，甚至可以嵌套列表：

```python
matrix = [[1, 2, 3], [4, 5, 6]]   # 二维列表
print(matrix[1])                  # [4, 5, 6]，第 2 个元素本身也是列表
print(matrix[1][2])               # 6，再从这个小列表里取索引 2
```

`matrix[1][2]` 从左往右读：先取 `matrix[1]` 得到 `[4, 5, 6]`，再取它的 `[2]`。可以把二维列表想象成表格：第一个索引选“行”，第二个索引选“列”。

## 7.2 访问与修改元素

列表的索引和切片规则与字符串完全一样（从 0 开始，支持负索引和切片）：

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]
print(fruits[0])     # 苹果
print(fruits[-1])    # 葡萄
print(fruits[1:3])   # ['香蕉', '橙子']
```

**与字符串不同的是，列表是“可变的”**——可以直接修改某个位置的元素：

```python
fruits[1] = "西瓜"
print(fruits)        # ['苹果', '西瓜', '橙子', '葡萄']
```

（字符串不能这样改，`s[0] = "x"` 会报错。）

### 注意：赋值不是复制

列表可变，这带来一个新手很容易踩的坑：

```python
a = [1, 2, 3]
b = a            # b 和 a 指向“同一个”列表，并没有复制
b.append(4)
print(a)         # [1, 2, 3, 4]  ← a 也变了！
```

变量更像是贴在数据上的**标签**，`b = a` 只是给同一个列表多贴了一张标签。想要一份独立的副本，用 `copy()` 或切片 `[:]`：

```python
a = [1, 2, 3]
c = a.copy()     # 或 c = a[:]
c.append(5)
print(a)         # [1, 2, 3]       ← a 不受影响
print(c)         # [1, 2, 3, 5]
```

## 7.3 列表的常用方法

### 增加元素

```python
lst = [1, 2, 3]
lst.append(4)         # 在末尾追加一个元素
print(lst)            # [1, 2, 3, 4]

lst.insert(0, 99)     # 在索引 0 处插入
print(lst)            # [99, 1, 2, 3, 4]

lst.extend([5, 6])    # 把另一个列表的元素逐个追加
print(lst)            # [99, 1, 2, 3, 4, 5, 6]
```

> 注意区别：`append([5,6])` 会把 `[5,6]` 作为**一个元素**加进去；`extend([5,6])` 是把 5 和 6 **分别**加进去。

### 删除元素

```python
lst = [10, 20, 30, 20]
lst.remove(20)        # 删除第一个值为 20 的元素
print(lst)            # [10, 30, 20]

x = lst.pop()         # 弹出并返回最后一个元素
print(x)              # 20
print(lst)            # [10, 30]

y = lst.pop(0)        # 弹出指定索引的元素
print(y)              # 10

del lst[0]            # 用 del 按索引删除
```

### 查找与统计

```python
lst = [10, 20, 30, 20]
print(len(lst))       # 4，元素个数
print(20 in lst)      # True，判断是否存在
print(lst.index(30))  # 2，返回第一次出现的索引
print(lst.count(20))  # 2，统计出现次数
```

### 常用内置函数：sum / max / min

除了 `len()`，下面几个**内置函数**也经常和列表一起用（注意它们是函数，写法是 `sum(lst)`，不是 `lst.sum()`）：

```python
scores = [88, 92, 79, 95, 63]
print(sum(scores))    # 417，求和
print(max(scores))    # 95，最大值
print(min(scores))    # 63，最小值
print(sum(scores) / len(scores))   # 83.4，平均值 = 总和 / 个数
```

### 排序与反转

```python
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort()               # 原地升序排序（改变原列表）
print(nums)               # [1, 1, 2, 3, 4, 5, 9]

nums.sort(reverse=True)   # 降序
print(nums)               # [9, 5, 4, 3, 2, 1, 1]

nums.reverse()            # 反转顺序
```

> `sort()` 会**改变原列表**并返回 `None`（`None` 表示“什么都没有”）。所以**千万不要写 `nums = nums.sort()`**，那样 `nums` 会变成 `None`。如果想保留原列表、得到一个新的排序结果，用内置函数 `sorted(nums)`。

```python
original = [3, 1, 2]
new = sorted(original)    # 不改变 original，返回新列表
print(original)           # [3, 1, 2]
print(new)                # [1, 2, 3]
```

## 7.4 遍历列表

```python
fruits = ["苹果", "香蕉", "橙子"]

# 直接遍历元素（最常用）
for fruit in fruits:
    print(fruit)

# 同时需要索引和元素时，用 enumerate
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# 0: 苹果
# 1: 香蕉
# 2: 橙子
```

`enumerate()` 会同时给出**索引**和**元素**，非常实用。`for i, fruit in ...` 这种一次给两个变量赋值的写法叫“解包”，7.7 节会专门讲。

## 7.5 列表推导式（List Comprehension）

这是 Python 极具特色的语法，用一行代码从旧列表生成新列表。

**基本形式**：`[表达式 for 变量 in 序列]`

```python
# 生成 1~5 的平方
squares = [x ** 2 for x in range(1, 6)]
print(squares)        # [1, 4, 9, 16, 25]
```

它等价于：

```python
squares = []
for x in range(1, 6):
    squares.append(x ** 2)
```

读推导式时，建议**先看中间的 `for`，再看最前面的表达式**：

```
[ x ** 2      for x in range(1, 6) ]
  ↑ ② 每个 x    ↑ ① 从 range(1, 6) 里
    变成什么        依次取出 x
```

“从 1~5 里依次取出 x，把 x 的平方放进新列表。”

**带条件筛选**：`[表达式 for 变量 in 序列 if 条件]`

```python
# 取出 1~20 中的偶数
evens = [x for x in range(1, 21) if x % 2 == 0]
print(evens)          # [2, 4, 6, ..., 20]

# 把字符串列表全部转成大写
words = ["hello", "world"]
upper = [w.upper() for w in words]
print(upper)          # ['HELLO', 'WORLD']
```

列表推导式简洁高效，是 Python 程序员的必备技能。初学时如果觉得绕，可以先用普通 `for` 循环写，理解后再逐步改用推导式。

## 7.6 元组：不可变的列表

**元组（tuple）**和列表很像，但用**圆括号 `()`**，而且**创建后不能修改**（不可变）：

```python
point = (3, 5)
print(point[0])      # 3，索引方式和列表一样
# point[0] = 10      # ✗ 报错！TypeError: 'tuple' object does not support item assignment

colors = ("红", "绿", "蓝")
print(len(colors))   # 3
```

> 定义**单个元素**的元组时，必须加逗号：`(5,)`。`(5)` 只是数字 5 加了括号，不是元组。

**为什么需要不可变的元组？**

- 表示“一组固定不变”的数据，如坐标 `(x, y)`、RGB 颜色 `(255, 0, 0)`。
- 更安全（防止被意外修改），性能也略优于列表。
- 可以作为字典的键（第 08 章的容器对比表里会讲到），而列表不行。

## 7.7 元组解包

可以把元组（或列表）里的多个值“一次性”赋给多个变量，这叫**解包**：

```python
point = (3, 5)
x, y = point          # 解包
print(x, y)           # 3 5
```

这其实就是第 02 章交换变量 `a, b = b, a` 背后的原理。函数返回多个值时也常用它（`def`/`return` 语法见第 09 章）：

```python
def min_max(nums):
    return min(nums), max(nums)   # 返回一个元组

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)      # 1 5
```

## 7.8 列表 vs 元组：如何选择

| 特性 | 列表 list | 元组 tuple |
| --- | --- | --- |
| 符号 | `[]` | `()` |
| 可变性 | 可变（能增删改） | 不可变 |
| 用途 | 需要频繁修改的数据 | 固定不变的一组数据 |
| 能否作字典键 | 否 | 能 |

**经验法则**：默认用列表；只有当你确定这组数据不该被改变时，才用元组。

## 新手常见错误

### ❶ 索引越界

```python
lst = [1, 2, 3]
print(lst[3])
```

```
IndexError: list index out of range
```

**原因**：3 个元素的列表，索引只有 `0`、`1`、`2`。
**改法**：最后一个元素用 `lst[-1]`；循环时用 `for x in lst` 直接遍历元素，而不是自己数索引。

### ❷ 把 `sort()` 的结果赋值回去

```python
nums = [3, 1, 2]
nums = nums.sort()
print(nums[0])
```

```
TypeError: 'NoneType' object is not subscriptable
```

**原因**：`sort()` 原地排序、返回 `None`，`nums` 被覆盖成了 `None`，`None` 不能用 `[0]` 取值（`not subscriptable` = 不能用下标访问）。
**改法**：直接写 `nums.sort()`；或者 `nums = sorted(nums)`。

### ❸ 删除不存在的元素

```python
lst = [1, 2, 3]
lst.remove(99)
```

```
ValueError: list.remove(x): x not in list
```

**原因**：`remove` 找不到要删的值。`lst.index(99)` 也会报类似的错。
**改法**：先判断：`if 99 in lst: lst.remove(99)`。

### ❹ `append` 一次传了多个值

```python
lst = [1, 2, 3]
lst.append(4, 5)
```

```
TypeError: list.append() takes exactly one argument (2 given)
```

**原因**：`append` 一次只能加**一个**元素（`takes exactly one argument` = 只接受一个参数，你给了 2 个）。
**改法**：加多个用 `lst.extend([4, 5])`。

### ❺ 一边遍历一边删除（不报错，但结果不对）

```python
nums = [1, 2, 2, 3]
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)          # [1, 2, 3]，还剩一个 2！
```

**原因**：删除元素后，后面的元素整体前移，循环会“跳过”紧挨着的下一个元素。
**改法**：不要修改正在遍历的列表，而是生成一个新列表：`nums = [n for n in nums if n != 2]`。

### ❻ 以为 `b = a` 复制了列表

见 7.2 节：`b = a` 之后修改 `b`，`a` 也会跟着变。需要独立副本时用 `a.copy()`。

## 本章小结

- 列表 `[]` 是**有序可变**的集合，支持索引、切片，可混装类型、可嵌套。
- 增删：`append`/`insert`/`extend`，`remove`/`pop`/`del`；查找：`in`/`index`/`count`/`len`。
- 排序：`sort()` 原地排序（返回 None，**不要**写 `x = x.sort()`），`sorted()` 返回新列表。
- `sum()` / `max()` / `min()` 是常用内置函数；`b = a` 不是复制，复制用 `a.copy()`。
- 遍历用 `for`，需要索引时用 `enumerate`。
- **列表推导式** `[表达式 for x in 序列 if 条件]` 一行生成新列表。
- 元组 `()` 是**不可变**的，适合固定数据；解包 `x, y = point` 很实用。
