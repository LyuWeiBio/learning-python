## 9.1 为什么需要函数

假设你要在程序里多次计算“圆的面积”，如果每次都写一遍 `3.14159 * r * r`，不仅啰嗦，改起来还容易出错。**函数**能把一段代码打包起来，起个名字，需要时“调用”它即可。

函数带来的好处：

- **复用**：写一次，到处调用。
- **清晰**：给一段逻辑起个有意义的名字，代码像读文章。
- **易维护**：逻辑集中在一处，改一处即全局生效。

其实我们早就用过函数了：`print()`、`len()`、`input()`、`int()` 都是 Python **内置函数**。本章学习如何定义**自己的**函数。

> **打个比方**：函数就像一台**榨汁机**。你放进去水果（**参数**），它按固定流程加工（**函数体**），最后吐出果汁（**返回值**）。榨汁机只需要造一次，以后想喝什么果汁，放进不同的水果就行。

## 9.2 定义与调用函数

用关键字 `def` 定义函数：

```python
def greet():
    print("你好！")
    print("欢迎学习 Python")

# 定义之后要“调用”它才会执行
greet()        # 调用
greet()        # 可以反复调用
```

结构解读：

- `def` 是定义函数的关键字。
- `greet` 是函数名（命名规则同变量：小写 + 下划线）。
- 一对括号 `()` 用来放参数（这里暂时为空）。
- 冒号 `:` 之后，缩进的部分是**函数体**。
- 定义不会执行函数体；只有**调用** `greet()` 时才执行。
- 调用时**括号不能省**：只写 `greet` 不会执行函数（也不会报错），必须写 `greet()`。
- 函数要**先定义、后调用**：Python 从上往下执行，如果调用写在 `def` 之前，会报 `NameError`。

## 9.3 参数：给函数传入数据

参数让函数能处理不同的数据。括号里写的叫**形参**，调用时传入的叫**实参**：

```python
def greet(name):            # name 是形参
    print(f"你好，{name}！")

greet("小明")               # "小明" 是实参 → 你好，小明！
greet("小红")               # 你好，小红！
```

可以有多个参数，用逗号分隔：

```python
def add(a, b):
    print(a + b)

add(3, 5)         # 8
```

调用时，实参默认**按位置**依次对应形参（第一个给第一个，第二个给第二个）。形参和实参的**个数要一致**：`add(3)` 少给了一个、`add(1, 2, 3)` 多给了一个，都会报 `TypeError`。

## 9.4 返回值：return

上面的函数只是打印，没有把结果“交回来”。用 `return` 可以让函数**返回一个结果**，供后续使用：

```python
def add(a, b):
    return a + b

result = add(3, 5)          # 把返回值存进变量
print(result)               # 8
print(add(10, 20) * 2)      # 返回值可以直接参与运算 → 60
```

`result = add(3, 5)` 这一行背后发生了什么？

1. 程序“跳进”函数 `add`，把 `3` 交给 `a`、`5` 交给 `b`；
2. 执行函数体，算出 `a + b` 得 `8`；
3. 遇到 `return 8`，带着 `8` “跳回”调用的地方；
4. 此时这一行相当于 `result = 8`。

可以把**函数调用整体看成它的返回值**：`add(10, 20) * 2` 就相当于 `30 * 2`。

### return 与 print 的区别（重点！）

初学者最容易混淆这两个：

- `print()` 只是把内容**显示**到屏幕上，程序拿不到这个值。
- `return` 是把结果**返回**给调用处，可以被存储、计算、传递。

```python
def add_print(a, b):
    print(a + b)            # 只显示，不返回

def add_return(a, b):
    return a + b            # 返回结果

x = add_print(3, 5)        # 屏幕显示 8，但 x 是 None！
y = add_return(3, 5)        # y 得到 8，可继续使用
print(x)                    # None
print(y + 1)                # 9
# print(x + 1)              # ✗ 报错：None 不能和数字相加
```

**怎么选？** 记住一条经验：**函数负责“算”，用 `return` 交出结果；要不要显示、怎么显示，交给调用它的地方决定。** 除非函数的任务本身就是“打印”（比如 `greet()`），否则优先用 `return`。

> **关键理解**：没有 `return` 的函数，默认返回 `None`。如果你想“用函数算出的结果”，就必须 `return`。

### return 会立即结束函数

一旦执行到 `return`，函数立刻结束，后面的代码不再执行：

```python
def check(score):
    if score >= 60:
        return "及格"
    return "不及格"          # 只有前面没 return 才会走到这

print(check(80))            # 及格
```

## 9.5 返回多个值

`return` 后面用逗号可以返回多个值，本质是返回一个**元组**，配合解包很好用：

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 7, 1, 9, 4])
print(low, high)            # 1 9
```

---

## 9.6 默认参数

给形参一个默认值，调用时如果不传，就用默认值：

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}！")

greet("小明")                    # 你好，小明！（用默认值）
greet("小红", "早上好")          # 早上好，小红！（覆盖默认值）
```

> **规则**：有默认值的参数必须放在**没有默认值的参数后面**。`def f(a=1, b)` 是错误的。

> **一个著名的坑**：不要用可变对象（如列表 `[]`）作默认值，比如 `def f(lst=[])`。这会导致多次调用共享同一个列表。初学阶段记住“默认值用不可变类型”即可，进阶后再深究。

---

## 9.7 关键字参数

调用时可以用 `参数名=值` 的形式明确指定，这叫**关键字参数**，好处是不用记参数顺序、可读性强：

```python
def create_user(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

# 按位置传
create_user("小明", 18, "北京")

# 用关键字传，顺序可以打乱
create_user(age=18, city="上海", name="小红")
```

位置参数必须在关键字参数**之前**。

---

## 9.8 文档字符串（docstring）

在函数体的第一行写一个字符串，用来说明函数的作用，这叫**文档字符串**。它是好习惯，也能被工具自动提取成文档：

```python
def circle_area(radius):
    """计算圆的面积。

    参数:
        radius: 圆的半径
    返回:
        面积（浮点数）
    """
    return 3.14159 * radius ** 2

print(circle_area.__doc__)      # 可以查看文档
help(circle_area)               # 或用 help() 查看
```

## 9.9 一个完整例子

把前面知识综合起来，写一个成绩处理函数：

```python
def analyze_scores(scores):
    """接收成绩列表，返回(平均分, 最高分, 及格率)。"""
    average = sum(scores) / len(scores)
    highest = max(scores)
    passed = len([s for s in scores if s >= 60])
    pass_rate = passed / len(scores)
    return average, highest, pass_rate

data = [88, 55, 92, 70, 45]
avg, high, rate = analyze_scores(data)
print(f"平均分：{avg:.1f}")
print(f"最高分：{high}")
print(f"及格率：{rate:.0%}")     # :.0% 会自动转成百分比
```

## 新手常见错误

### ❶ 调用时参数个数不对

```python
def greet(name):
    print(name)

greet()
```

```
TypeError: greet() missing 1 required positional argument: 'name'
```

**原因**：`greet` 需要 1 个参数 `name`，调用时一个也没给（`missing ... argument` = 缺少参数）。反过来，多给了参数会报 `takes 2 positional arguments but 3 were given`。
**改法**：对照 `def` 那一行，看看函数需要几个参数，调用时一一对应。

### ❷ 忘了 `return`，拿到的是 `None`

```python
def add(a, b):
    print(a + b)          # 只打印，没有 return

result = add(1, 2)
print(result + 1)
```

```
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

**原因**：函数没有 `return`，默认返回 `None`，`result` 是 `None`。报错里出现 `NoneType`，十有八九是**某个函数忘了 `return`**。
**改法**：把 `print(a + b)` 改成 `return a + b`。

### ❸ 先调用、后定义

```python
greet()
def greet():
    print("hi")
```

```
NameError: name 'greet' is not defined
```

**原因**：Python 从上往下执行，运行到第 1 行时还不知道 `greet` 是什么。
**改法**：把 `def` 写在调用之前。通常的习惯是：所有函数定义写在文件上面，调用代码写在最下面。

### ❹ 调用时忘了括号

```python
greet           # 什么也没发生
print(greet)    # <function greet at 0x7f01c981ce00>
```

**原因**：不带括号只是“提到了”这个函数，并没有调用它。这个错误**不会报错**。
**改法**：`greet()`。

### ❺ 参数顺序写错

```python
def f(a=1, b):
    pass
```

```
SyntaxError: parameter without a default follows parameter with a default
```

**原因**：有默认值的参数必须放在没有默认值的参数后面。调用时也一样，`create_user(name="a", 18, "北京")` 会报 `positional argument follows keyword argument`（位置参数不能跟在关键字参数后面）。
**改法**：定义时写成 `def f(b, a=1)`；调用时先写位置参数，再写关键字参数。

## 本章小结

- 用 `def 函数名(参数):` 定义函数，缩进部分是函数体；调用时才执行。
- 参数让函数处理不同数据；调用时按位置或按关键字传参。
- `return` 把结果交回调用处；**没有 return 的函数返回 `None`**。
- `return` 与 `print` 完全不同：一个返回值、一个只显示；报错里出现 `NoneType` 时，先检查是不是忘了 `return`。
- `return a, b` 返回多个值（元组），可解包接收。
- 默认参数要放在后面；文档字符串（docstring）说明函数用途。

**第 1 题**：

```python
def c_to_f(c):
    return c * 9 / 5 + 32

print(c_to_f(0))       # 32.0
```

**第 2 题**：

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):     # 逐个试除 2 ~ n-1
        if n % i == 0:
            return False      # 找到因子，立刻结束函数
    return True               # 循环走完都没找到因子，是质数

for num in range(1, 51):
    if is_prime(num):
        print(num, end=" ")   # 2 3 5 7 11 ... 47
```

> **进阶优化**：其实只需要试除到 √n 就够了（如果 n 有一个大于 √n 的因子，就一定有一个对应的小于 √n 的因子）。把循环改成 `range(2, int(n ** 0.5) + 1)`，数字很大时会快很多（`n ** 0.5` 就是 n 的平方根）。

**第 3 题**：

```python
def power(base, exp=2):
    return base ** exp

print(power(5))         # 25
print(power(2, 10))     # 1024
```

**第 4 题**：

```python
def divide(a, b):
    return a // b, a % b

q, r = divide(17, 5)
print(f"商 {q}，余 {r}")   # 商 3，余 2
```

**第 5 题**：

```python
def word_stats(sentence):
    words = sentence.split()
    count = len(words)
    lengths = [len(w) for w in words]   # 每个单词的长度，如 [5, 5, 6, 11]
    avg_len = sum(lengths) / count
    return count, avg_len

n, avg = word_stats("hello world python programming")
print(f"{n} 个单词，平均长度 {avg:.1f}")
```
