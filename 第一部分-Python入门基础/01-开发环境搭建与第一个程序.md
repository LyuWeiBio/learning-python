## 1.1 Python 是什么

Python 是一门**通用编程语言**，由 Guido van Rossum 于 1991 年发布。它的设计哲学强调**代码的可读性**，语法简洁、接近自然语言，因此非常适合初学者。

Python 的应用非常广泛：

| 领域 | 举例 |
| --- | --- |
| 数据分析 / 数据科学 | 处理表格、统计分析、可视化 |
| 人工智能 / 机器学习 | 图像识别、推荐系统、大语言模型 |
| Web 后端开发 | 网站、API 服务（Django、Flask、FastAPI） |
| 自动化 / 脚本 | 批量处理文件、爬虫、办公自动化 |
| 科学计算 | 物理、生物、金融建模 |

> 本教程的最终目标是**机器学习实战**，而 Python 正是当今机器学习领域最主流的语言，几乎所有主流框架（scikit-learn、PyTorch、TensorFlow）都以 Python 为主要接口。

## 1.2 安装 Python

### 方法一：官方安装包（推荐初学者）

1. 打开浏览器访问官网：<https://www.python.org/downloads/>
2. 点击黄色的 **Download Python 3.x.x** 按钮（选择 3.10 及以上版本）。
3. 运行下载好的安装程序。

> **Windows 用户特别注意**：安装第一步的窗口底部，务必勾选 **“Add Python to PATH”（把 Python 添加到环境变量）**，然后再点击 “Install Now”。这一步能让你在命令行里直接使用 `python` 命令。

- **Windows**：勾选 “Add Python to PATH” → Install Now。
- **macOS**：下载 `.pkg` 安装包，一路“继续”即可；macOS 也可用 `brew install python`。
- **Linux**：大多数发行版自带 Python 3，也可用包管理器安装，例如 Ubuntu：`sudo apt install python3 python3-pip`。

### 验证安装是否成功

打开你的**终端**（命令行）：

- Windows：按 `Win + R`，输入 `cmd` 回车；或搜索“PowerShell”。
- macOS：打开“终端”(Terminal) 应用。
- Linux：`Ctrl + Alt + T`。

在终端中输入下面的命令并回车：

```bash
python --version
```

如果显示类似 `Python 3.12.3` 的版本号，说明安装成功！

> **常见坑**：如果提示“找不到命令”，在 Windows 上试试 `py --version`，在 macOS/Linux 上试试 `python3 --version`。很多系统里 `python3` 才是正确的命令名。本教程后文统一写 `python`，你需要根据自己的系统替换成 `python3` 或 `py`。

**安装失败时的几种典型表现：**

| 你看到的现象 | 原因 | 解决办法 |
| --- | --- | --- |
| Windows 提示 `'python' 不是内部或外部命令，也不是可运行的程序` | 安装时没勾选 “Add Python to PATH” | 重新运行安装包，选 “Modify”，勾选 “Add Python to environment variables”；或直接卸载重装并勾选 PATH |
| Windows 输入 `python` 后弹出了 Microsoft Store 应用商店 | 系统自带的“占位快捷方式”抢先响应了 | 先确认已经按上面步骤装好 Python；再在 Windows 设置里搜索“应用执行别名”，把其中的 `python.exe` 和 `python3.exe`（“应用安装程序”）关掉，然后重开终端 |
| 显示的版本是 `Python 2.7.x` | 系统里还有老版本 Python 2 | 改用 `python3` 命令 |
| 装完了，但旧终端里还是找不到命令 | 终端是在安装之前打开的，没读取到新设置 | **关掉终端重新打开**（必要时重启电脑） |

## 1.3 两种运行 Python 的方式

### 方式一：交互式解释器（Interactive Mode）

在终端里直接输入 `python`（或 `python3`）回车，你会看到 `>>>` 提示符，这就是 Python 的**交互式解释器**，可以一行一行地即时执行代码：

```python
>>> 1 + 1
2
>>> print("你好")
你好
>>> 10 * 8
80
```

交互式解释器非常适合**做实验、验证想法**。输入 `exit()` 或按 `Ctrl + D`（Windows 上是 `Ctrl + Z` 再回车）退出。

> **分清“我现在在哪儿”**：新手最容易混淆的就是这两种提示符——
>
> - 行首是 `>>>`：你在 **Python 解释器里**，只能输入 Python 代码（如 `print("hi")`）。
> - 行首是 `C:\Users\你的名字>`、`PS C:\...>` 或 `你的名字@电脑 ~ %`、`$`：你在 **终端（命令行）里**，这里输入的是系统命令（如 `python hello.py`、`cd`）。
>
> 如果在 `>>>` 后面输入 `python hello.py`，会得到 `SyntaxError: invalid syntax`——这时先 `exit()` 退出解释器，回到终端再运行。

### 方式二：运行脚本文件（Script Mode）

真正开发时，我们把代码写在一个以 `.py` 结尾的文件里，然后一次性运行整个文件。这就是**脚本模式**，也是本教程的主要方式。

假设有一个文件 `hello.py`，在终端里运行它的命令是：

```bash
python hello.py
```

## 1.5 你的第一个程序：Hello, World!

按照编程界的传统，第一个程序永远是打印一句 “Hello, World!”。

在 VS Code 左侧的资源管理器里，把鼠标移到文件夹名上，点击“新建文件”图标（带 `+` 的纸张），输入文件名 `hello.py` 回车，然后输入以下内容：

> 文件名一定要以 `.py` 结尾。不要用记事本新建，Windows 默认隐藏扩展名，很容易得到 `hello.py.txt` 这种“假” Python 文件。

```python
print("Hello, World!")
print("我的第一个 Python 程序")
```

按 `Ctrl + S`（macOS 是 `Cmd + S`）保存。

> **没保存就运行，跑的还是旧代码！** VS Code 里文件标签上有个**白色圆点 ●**，就表示还没保存。养成“改完先保存再运行”的习惯。

接下来运行它。有两种做法，任选其一：

**做法 A：在 VS Code 里点按钮（最简单）**

点击编辑器右上角的 **▶（Run Python File）** 按钮，VS Code 会在下方自动打开终端并运行当前文件。

**做法 B：在终端里输入命令（必须学会）**

1. 在 VS Code 里按 `` Ctrl + ` ``（反引号键，在键盘左上角 `Esc` 下面）打开内置终端。
   用 VS Code 打开文件夹后，内置终端默认就在这个文件夹里。
2. 输入下面的命令并回车：

```bash
python hello.py
```

如果你用的是系统自带的终端（而不是 VS Code 内置的），需要先用 `cd` 命令“走进”文件所在的文件夹：

```bash
cd 文件夹路径          # 例如 Windows：cd C:\Users\小明\python-learning
                       #      macOS：  cd ~/python-learning
python hello.py
```

> **小技巧**：输入 `cd ` （注意后面有个空格）之后，直接把文件夹从资源管理器 / 访达拖进终端窗口，路径会自动填好。
> 不确定当前在哪个文件夹？Windows 输入 `dir`、macOS/Linux 输入 `ls`，看看列出的文件里有没有 `hello.py`。

无论哪种做法，你都会看到输出：

```
Hello, World!
我的第一个 Python 程序
```

🎉 恭喜！你已经成功运行了人生第一个 Python 程序。

### 拆解这行代码

```python
print("Hello, World!")
```

- `print` 是一个**函数**，作用是把内容“打印”到屏幕上。
- 一对小括号 `()` 表示“调用”这个函数。
- 括号里的 `"Hello, World!"` 是一段**字符串**（文本），必须用引号（单引号 `'` 或双引号 `"` 都行）包起来。

> **务必使用英文标点**！代码里的括号、引号、逗号都必须是英文半角符号。中文的 `（）"" ，` 会导致报错，这是初学者最常见的错误之一。

## 1.6 注释：写给人看的说明

**注释**是给人阅读的说明文字，Python 在运行时会完全忽略它。用 `#` 号开头表示单行注释：

```python
# 这是一行注释，程序不会执行它
print("Hello")  # 井号后面的内容也是注释

# 下面这行被注释掉了，不会运行
# print("我不会被打印")
```

多行说明可以用三引号 `"""` 包裹（严格来说它是一个“文档字符串”，但常被当多行注释用）：

```python
"""
这是一段
多行说明文字。
通常用于解释整个文件或函数的作用。
"""
print("正文代码")
```

**为什么要写注释？** 因为几个月后的你，可能会完全看不懂现在写的代码。好的注释解释“为什么这么做”，而不是简单复述“做了什么”。

## 1.7 关于报错：别怕，它是你的朋友

初学时你一定会遇到各种报错（Error），这非常正常。例如把 `print` 拼错成 `prin`：

```python
prin("Hello")
```

运行会得到：

```
Traceback (most recent call last):
  File "C:\Users\小明\python-learning\hello.py", line 1, in <module>
    prin("Hello")
    ^^^^
NameError: name 'prin' is not defined. Did you mean: 'print'?
```

### 三步读懂报错

报错看起来吓人，其实可以按固定顺序读：

1. **先看最后一行**：`NameError: name 'prin' is not defined` —— 冒号前是**错误类型**（`NameError`，名字错误），冒号后是**原因**（名字 `prin` 没有定义）。
2. **再看 `line 几`**：`line 1` 告诉你问题出在第 1 行，`^^^^` 还会指出这一行里具体哪个位置。
3. **留意 `Did you mean`**：Python 3.10 以后，很多报错会直接给出建议——这里它猜你想写的是 `print`。

> 报错是英文的？不用怕，只需认识几个常见的错误类型单词。本教程附录 [新手报错速查表](../附录-新手报错速查.md) 整理了最常见的报错、中文含义和排查方法，遇到看不懂的报错可以先去那里查。

我们在第 13 章会系统学习异常与报错处理，现在你只需记住：**报错不可怕，它在帮你找 bug**。

## 新手常见错误

> 下面这几个错误，几乎每个初学者第一周都会遇到。先认识它们长什么样，下次就能一眼认出来。

### ❶ 用了中文标点

```python
print（"你好"）
```

```
SyntaxError: invalid character '（' (U+FF08)
```

**原因**：`（` 是中文全角括号。报错里的 `invalid character`（非法字符）几乎总是指中文标点。
**改法**：切换到英文输入法后重新输入括号、引号、逗号、冒号：`print("你好")`。

### ❷ 引号或括号没有成对

```python
print("你好)
print("你好"
```

```
SyntaxError: unterminated string literal (detected at line 1)
SyntaxError: '(' was never closed
```

**原因**：第一行的字符串少了结尾的 `"`（`unterminated string` = 字符串没有结束）；第二行少了右括号 `)`（`never closed` = 从没关上）。
**改法**：引号、括号都要**成对出现**。VS Code 会自动补全另一半，尽量不要手动删掉它。

### ❸ 大小写写错

```python
Print("hi")
```

```
NameError: name 'Print' is not defined. Did you mean: 'print'?
```

**原因**：Python **区分大小写**，`Print` 和 `print` 是两个不同的名字。
**改法**：改成全小写的 `print`。

### ❹ 行首多了空格

```python
  print("hi")
```

```
IndentationError: unexpected indent
```

**原因**：Python 用行首的空格（缩进）表示代码层级（第 05 章会讲），普通语句前面不能随便加空格。
**改法**：删掉行首的空格，让代码顶格写。

### ❺ 在错误的地方运行命令

```
python: can't open file 'C:\\Users\\小明\\hello.py': [Errno 2] No such file or directory
```

**原因**：终端当前所在的文件夹里没有 `hello.py`。
**改法**：先 `cd` 到 `hello.py` 所在的文件夹再运行，或者直接用 VS Code 打开文件夹后使用内置终端。另外别忘了：在 `>>>` 后面输入 `python hello.py` 也会报错，要先 `exit()` 回到终端。

## 本章小结

- Python 是一门简洁易读、应用广泛的语言，是数据分析与机器学习的首选。
- 从官网安装 Python，并用 `python --version` 验证。
