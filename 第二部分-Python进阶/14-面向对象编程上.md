## 14.1 什么是面向对象

之前我们用变量存数据、用函数处理数据，数据和操作是**分开**的。**面向对象编程（Object-Oriented Programming, OOP）**换了一种思路：把**数据**和**操作数据的方法**捆绑在一起，形成一个个“对象”。

打个比方：

- **类（class）** 是“模板 / 图纸”，比如“狗”这个概念。
- **对象（object / 实例 instance）** 是按图纸造出来的“具体实物”，比如你家那只叫“旺财”的狗。

一个类可以创建出无数个对象，每个对象有自己的数据，但共享同样的方法。生活中处处是对象：一个学生、一辆车、一个银行账户……OOP 让代码更贴近现实、更易组织。

其实我们一直在用对象：字符串是 `str` 类的对象，列表是 `list` 类的对象，`"abc".upper()` 就是在调用字符串对象的方法。

**不用类会怎样？** 假设要管理两个银行账户，只用字典和函数：

```python
acc1 = {"owner": "小明", "balance": 100}
acc2 = {"owner": "小红", "balance": 50}

def deposit(acc, amount):
    acc["balance"] += amount

deposit(acc1, 30)
print(acc1["balance"])    # 130
```

能用，但数据（字典）和操作（函数）是“散装”的：键名写错一个字母就出错，别人也很难一眼看出“哪些函数是给账户用的”。学完本章，你会用类把它们“打包”成一个整体（14.4 节的 `BankAccount`）。

> 第一次接触 OOP 觉得抽象很正常。建议**先把本章的代码原样敲一遍、跑起来**，再回头读概念，会容易很多。

## 14.2 定义第一个类

```python
class Dog:
    def bark(self):
        print("汪汪汪！")

# 创建对象（实例化）
my_dog = Dog()        # 注意有括号
my_dog.bark()         # 汪汪汪！
```

- `class Dog:` 定义了一个名为 `Dog` 的类（类名习惯用**大驼峰**，即首字母大写，如 `MyClass`）。
- `bark` 是类里的**方法**（定义在类里的函数）。
- `Dog()` 创建了一个对象，`my_dog.bark()` 调用它的方法。

那个神秘的 `self` 是什么？往下看。

## 14.3 __init__ 与 self

大多数对象在创建时需要一些初始数据。`__init__` 是一个特殊方法（叫**构造方法/初始化方法**），在创建对象时**自动执行**，用来设置对象的初始属性：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name      # 把参数保存为对象的属性
        self.age = age

    def bark(self):
        print(f"{self.name} 说：汪汪汪！")

# 创建对象时传入参数（会自动传给 __init__）
dog1 = Dog("旺财", 3)
dog2 = Dog("小黑", 5)

print(dog1.name)     # 旺财，访问属性
print(dog2.age)      # 5
dog1.bark()          # 旺财 说：汪汪汪！
dog2.bark()          # 小黑 说：汪汪汪！
```

### 理解 self（重点）

- `self` 代表**对象自己**。每个方法的第一个参数都必须是 `self`（名字是约定，可改但别改）。
- 当你写 `dog1.bark()` 时，Python 自动把 `dog1` 作为 `self` 传进去。所以方法内部通过 `self.name` 就能访问到**这个对象自己**的数据。
- `self.name = name` 的意思是：把传进来的参数 `name`，保存成“这个对象的 `name` 属性”。

> 初学者常问：为什么调用 `dog1.bark()` 不用传 self？因为 `dog1.` 这个“点”前面的对象会**自动**成为 self。你只需在定义时写上 self，调用时不用管它。

其实 `dog1.bark()` 只是一种简写，Python 在背后把它翻译成了：

```python
Dog.bark(dog1)       # 和 dog1.bark() 效果完全相同：dog1 被传给了 self
```

这样看就清楚了：`self` 就是一个普通的参数，只不过 Python 会自动把“点前面的对象”填进去。所以同一个 `bark` 方法，`dog1.bark()` 时 `self` 是旺财，`dog2.bark()` 时 `self` 是小黑。

> **`__init__` 的写法要一字不差**：`init` 前后**各两个**下划线。写成 `_init_` 或 `__int__`，Python 不会把它当成初始化方法，创建对象时就会报错（见本章“新手常见错误”）。

## 14.4 属性与方法

- **属性（attribute）**：对象拥有的数据，如 `dog1.name`、`dog1.age`。
- **方法（method）**：对象能执行的操作（定义在类里的函数），如 `dog1.bark()`。

方法内部可以自由使用和修改属性：

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print(f"存入 {amount}，余额 {self.balance}")

    def withdraw(self, amount):
        if amount > self.balance:
            print("余额不足！")
        else:
            self.balance -= amount
            print(f"取出 {amount}，余额 {self.balance}")

acc = BankAccount("小明", 100)
acc.deposit(50)       # 存入 50，余额 150
acc.withdraw(200)     # 余额不足！
acc.withdraw(80)      # 取出 80，余额 70
```

这个例子很好地体现了 OOP 的思想：`balance`（数据）和 `deposit`/`withdraw`（操作）被封装在一起，外界通过方法来安全地操作数据。

## 14.5 实例属性 vs 类属性

- **实例属性**：在 `__init__` 里用 `self.xxx` 定义，**每个对象各有一份**。
- **类属性**：直接定义在类体中，**所有对象共享**。

```python
class Dog:
    species = "犬科"          # 类属性，所有狗共享

    def __init__(self, name):
        self.name = name       # 实例属性，每只狗不同

dog1 = Dog("旺财")
dog2 = Dog("小黑")

print(dog1.species)          # 犬科
print(dog2.species)          # 犬科（共享同一个）
print(Dog.species)           # 犬科（也能通过类名访问）

print(dog1.name, dog2.name)  # 旺财 小黑（各自不同）
```

类属性常用来存放“所有对象都一样的常量”或“统计信息”，比如统计一共创建了多少个对象：

```python
class Dog:
    count = 0                 # 记录总数

    def __init__(self, name):
        self.name = name
        Dog.count += 1        # 每创建一个就 +1

Dog("A"); Dog("B"); Dog("C")  # 分号 ; 可以把多条语句写在一行（了解即可，不推荐常用）
print(Dog.count)             # 3
```

## 14.6 __str__：让对象更“可读”

直接打印一个对象，默认会显示一串没啥用的信息：

```python
class Dog:
    def __init__(self, name):
        self.name = name

d = Dog("旺财")
print(d)     # <__main__.Dog object at 0x000...>  看不懂
```

定义特殊方法 `__str__`，可以自定义打印时的显示内容：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"狗狗({self.name}, {self.age}岁)"

d = Dog("旺财", 3)
print(d)         # 狗狗(旺财, 3岁)
```

像 `__init__`、`__str__` 这种前后带双下划线的方法，称为**魔术方法/特殊方法**（dunder methods），Python 会在特定时机自动调用它们。第 15 章还会学到更多。

> `__str__` 必须 **`return` 一个字符串**，而不是在里面 `print`。它的任务是“告诉 Python 该显示什么”，真正的显示交给外面的 `print(d)`。

## 新手常见错误

### ❶ 定义方法时忘了写 `self`

```python
class Dog:
    def bark():
        print("汪")

d = Dog()
d.bark()
```

```
TypeError: Dog.bark() takes 0 positional arguments but 1 was given
```

**原因**：`d.bark()` 会自动把 `d` 作为第一个参数传进去，但 `bark()` 一个参数都不接收（“定义了 0 个参数，却收到了 1 个”）。
**改法**：类里的每个方法，第一个参数都写 `self`：`def bark(self):`。

### ❷ 在方法里忘了写 `self.`

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{name} 说：汪汪汪！")

Dog("旺财").bark()
```

```
NameError: name 'name' is not defined. Did you mean: 'self.name'?
```

**原因**：`name` 只是 `__init__` 的局部变量，`__init__` 结束就没了；保存在对象身上的是 `self.name`。
**改法**：在方法里访问属性，一律写 `self.属性名`。同理，在 `__init__` 里写成 `name = name`（漏了 `self.`）也不会保存属性，之后访问 `d.name` 会报 `AttributeError`。

### ❸ `__init__` 拼错了

```python
class Dog:
    def _init_(self, name):     # 两边只有一个下划线
        self.name = name

d = Dog("旺财")
```

```
TypeError: Dog() takes no arguments
```

**原因**：Python 找不到真正的 `__init__`，认为这个类创建对象时不需要参数。
**改法**：`def __init__(self, name):`，前后各两个下划线。

### ❹ 创建对象时忘了括号

```python
d = Dog              # 少了括号
d.bark()
```

```
TypeError: Dog.bark() missing 1 required positional argument: 'self'
```

**原因**：`d = Dog` 只是给“类”起了个别名，并没有创建对象，所以调用方法时没有对象可以填进 `self`。
**改法**：`d = Dog()`。

### ❺ 属性名拼错

```python
d = Dog("旺财")
print(d.nmae)
```

```
AttributeError: 'Dog' object has no attribute 'nmae'
```

**原因**：对象身上没有 `nmae` 这个属性（`has no attribute` = 没有这个属性）。
**改法**：检查拼写，对照 `__init__` 里 `self.xxx = ...` 定义的名字。

### ❻ `__str__` 里用了 `print` 而不是 `return`

```python
def __str__(self):
    print(f"狗狗 {self.name}")
```

```
TypeError: __str__ returned non-string (type NoneType)
```

**原因**：`__str__` 没有 `return`，默认返回 `None`，而 Python 要求它返回字符串。
**改法**：`return f"狗狗 {self.name}"`。

## 本章小结

- OOP 把**数据（属性）**和**操作（方法）**封装在一起。类是模板，对象是实例。
- `class 类名:` 定义类（大驼峰命名）；`类名()` 创建对象。
- `__init__(self, ...)` 是构造方法，创建对象时自动执行，用来初始化属性。
- `self` 代表对象自己；方法第一个参数必须是 self，调用时自动传入（`d.bark()` 等价于 `Dog.bark(d)`）。
- 在方法里访问属性要写 `self.属性名`；`__init__`、`__str__` 前后各两个下划线。
- 实例属性（`self.x`，各对象独立）vs 类属性（写在类体，所有对象共享）。
- `__str__` 自定义对象的打印显示。

class Counter:

**第 5 题**：
